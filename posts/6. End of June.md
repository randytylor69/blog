## C++ Concepts Learned

&nbsp;

**String `split`, `splice`, `contains`, `erase`... (importing only the `std` library)**
- The `split` function is a headache; I gotta write ~5 lines of code and import 4 `std` libraries, unlike a one-liner Python solution.

**Data Type Casting**
- It took me a week to realize `static_cast<>` exists

**Pass by Reference/Value**
- Pass by ref (`foo(const vector<int> &bar)`) for expensive types, and pass by value for simple types (`int`, `char`, `bool`, etc.)

**OOP**
- Apart from the constructor requires **member initialization**, it's pretty much the same as other languages(getters, setters, overriders, etc.) - though I didn't touch polymorphism/inheritance

**Headers**
- A great way to export/import functions between files when the project gets large

**Data Structures**
- Fun and engaging ways to store data, such as `tuple`, `vector` and `map` (C++'s dictionary)
- Learned about versatile arrays: for certain algorithms, arrays could be used as fast and simple dictionaries (index as keys, cell as values)

**Algorithms**
- Fun and engaging ways to manipulate data, such as `DFS`, `BFS`, `Union Find`, `Powerset`, etc.
