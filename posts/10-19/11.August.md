With a frontend co-op position secured for the next 8 months (possibly the worst choice I've made so far), more time could be allocated to building a music TUI from scratch, a project that has been sitting on my summer bucket list for far too long. Now that the summer is virtually over, I failed to see a better time to start it than right this moment, turning all the guilt, shame and jealousy into motivation.

&nbsp;

## Requirements 

- A TUI music player built for Linux in modern C++ that runs entirely in the terminal
- Album arts attached
- Learning how music is materialized, bit rates, frequencies, file formats, metadata, etc.
